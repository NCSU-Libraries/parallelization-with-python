Why not a GPU for everything?

CPU: a few strong cores

GPU: thousands of simple cores

This laptop: 14 CPU cores.

An NVIDIA T4, the GPU Colab’s free tier usually gives you: 2,560 cores.

Each CPU core can run a different program, with its own branches and loops.

A GPU group of 32 does the same step at the same moment, each core on different data.

When cores in one group need different branches, they take turns, so half the group waits.
