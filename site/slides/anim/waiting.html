One worker can juggle waiting tasks: threads and asyncio. Not today.

Threads take turns running Python code, one at a time (the GIL).

Separate processes each run their own Python: real parallel computing. That's multiprocessing.

Python 3.13 and later offer an optional build without the GIL. Standard installs, and Colab, still have it.
